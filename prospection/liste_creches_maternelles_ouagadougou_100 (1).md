## Conseils pour ta prospection Petit Baobab

Pour constituer une vraie base commerciale, ajoute ensuite ces colonnes :

- `Nom du directeur / responsable`
- `WhatsApp confirmé`
- `Facebook`
- `Email`
- `Site web`
- `Nombre approximatif d'enfants`
- `Type : crèche / maternelle / bilingue / primaire`
- `Intérêt Petit Baobab`
- `Date du premier contact`
- `Statut : à contacter / contacté / intéressé / démo / client`
- `Notes`

**Priorité commerciale suggérée :** commencer par les structures bilingues, Montessori, crèches-maternelles privées et établissements qui publient régulièrement sur Facebook/WhatsApp. Ce sont généralement les prospects les plus naturels pour l'Assistant pédagogique et les ressources créatives Petit Baobab.
